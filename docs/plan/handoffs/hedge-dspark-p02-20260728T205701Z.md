Important semantic choices, all recorded with full hashes in the identity
file:

1. Only `value_scheme=normalized_suffix` is valid. `suffix` and
   `unlocked_tokens` were not copied.
2. Python uses descriptive field names; the canonical config mapping and
   fingerprint use exactly `B`, `g`, `m`, `value_scheme`, `block_size`.
3. `m` counts relaxed mismatches. The source name
   `max_relaxed_tokens_per_block` was renamed accordingly.
4. `block_size` is mandatory; `None` cannot disable mismatch detection.
5. The exact plan affordability inequality is used without the source
   implementation's `+1e-9` slack.
6. A mismatch needs positive budget immediately before that mismatch. Thus
   `B=0` rejects a zero-regret tie, and an earlier mismatch that exactly
   exhausts `B` makes later mismatches strict, including in the same block.
7. The pure reference owns `RequestRiskState.reset`; stable slot identity,
   reorder, abort/finish and device cleanup belong to P03.
8. The tensor interface consumes compact
   `top_logit/top_token_id/draft_logit` only. It has no `.item()` call or
   host-side state update.
