## 根因证据

正式 CUDA root：

```text
/home/tiger/venvs/deepspec-dspark/lib/python3.11/site-packages/nvidia/cu13
```

它包含：

```text
lib/libcudart.so.13
lib/libnvrtc.so.13
```

但不包含：

```text
lib64/
lib/libcudart.so
lib/libnvrtc.so
```

FlashInfer 最终 link command 使用：

```text
-L${CUDA_ROOT}/lib64 -L${CUDA_ROOT}/lib64/stubs
-lcudart -lcuda -lnvrtc
```

因此 linker 同时缺少正确的搜索目录和 unversioned development soname。

秒级、无 GPU 的反馈环脚本：

```text
scripts/phase05_cuda_link_probe.sh
```

worker 上的结果：

```text
current layout: returncode=1
  cannot find -lcudart
  cannot find -lnvrtc

temporary overlay: returncode=0
```

临时 overlay 只增加：

```text
lib64/libcudart.so -> ${CUDA_ROOT}/lib/libcudart.so.13
lib64/libnvrtc.so  -> ${CUDA_ROOT}/lib/libnvrtc.so.13
```

直接指定 versioned library 的 link 也返回 0，两个文件均为有效 x86-64 ELF，因而排除
库损坏和 architecture/ABI 不匹配。
